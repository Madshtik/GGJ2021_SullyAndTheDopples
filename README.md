# GGJ2021_SullyAndTheDopples
This is the git repository for the Global Game Jam Online 2021. Members are Sultan, Nemah, and Seth.


## Open the Unity project

Open this repository folder directly in Unity Hub using Unity 2020.2.2f1. Assets, Packages, and ProjectSettings are at the repository root. The local Nemah branch includes the merged Sully changes.

Unity caches, logs, local UserSettings, and the existing Build.rar archive are excluded from Git. Keep asset .meta files in version control.
